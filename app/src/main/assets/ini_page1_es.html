GPS para localización

Para rastrear una ruta, la aplicación debe tener permiso para usar los servicios de ubicación del teléfono.

La ubicación debe establecerse preferiblemente de una manera de alta precisión, con todas las redes GPS, Wi-Fi y móviles habilitadas. Si bien el GPS es esencial, las redes WiFi / móviles proporcionan datos que aceleran la determinación de la ubicación inicial, pero son opcionales: si no está habilitada, la definición de la ubicación inicial también puede tardar unos minutos.
