GPX Files and Photos

This app stores permanently photos and tracks (GPX files) into a dedicated storage directory that won’t be destroyed even if the app is uninstalled.

With the button below you will open a system window where you shall create this directory and then grant your access consent. The suggested name of this directory is “AGPS-Tracker”.

Warning: the window opens showing the contents of an already existing directory (e.g. "Downloads"). You must use the commands in the menu to create a directory at the same level of system directories like "Alarms" , "Downloads" , "Pictures", etc. Unfortunately this is not an easy operation for all users, if you have any doubts try to see the demo video and repeat the operation.

In case you already installed previous versions of this app, the directory “AGPS-Tracker” already exists but you shall still grant your access consent.
