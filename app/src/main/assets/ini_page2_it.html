Memorizzazione di Tracce e Foto

Questa app memorizza in modo permanente foto e tracce (file GPX) in una directory di archiviazione dedicata che rimane anche se l'app viene disinstallata.

Con il pulsante qui sotto si aprirà una finestra di sistema in cui si deve prima creare questa directory e poi concedere il consenso di accesso.

Il nome suggerito di questa directory è "AGPS-Tracker".

Attenzione: La finestra si apre mostrando il contenuto di una directory già esistente (ad esempio "Downloads"). Voi dovete usare i comandi nel menu di questa finestra per creare una directory allo stesso livello delle directory di sistema: Alarms, Downloads, Android, Pictures, etc. Purtroppo questa non è una operazione facile per tutti gli utenti, se avete dei dubbi provate a vedere il demo video e ripetete l'operazione.

Nel caso in cui abbiate già installato versioni precedenti di questa applicazione allora “AGPS-Tracker” esiste già, ma è necessario concederne il consenso di accesso.
