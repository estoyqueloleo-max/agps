Armazenamento de faixas e fotografias

Este aplicativo armazena permanentemente fotos e faixas (arquivos GPX) em um diretório de armazenamento dedicado que não será destruído, mesmo se o aplicativo for desinstalado.

Com o botão abaixo abrirá uma janela do sistema onde você deve criar este diretório e conceder o consentimento de acesso. O nome sugerido deste diretório é "AGPS-Tracker".

Aviso: a janela é aberta mostrando o conteúdo de um diretório já existente (por exemplo, "Downloads"). Você deve usar os comandos no menu para criar um diretório no mesmo nível de diretórios do sistema como "Alarms" , "Downloads" , "Pictures", etc. Infelizmente, esta não é uma operação fácil para todos os usuários, se você tiver alguma dúvida, tente ver o vídeo de demonstração e repita a operação.

No caso de você já ter instalado versões anteriores desta aplicação "AGPS-Tracker" já existe, mas você deve conceder consentimento para o acesso.
