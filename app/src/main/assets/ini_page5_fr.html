L'Information De Base.

Pour voir votre emplacement sur la carte, vous n'aurez pas besoin d'internet, mais vous devez télécharger deux types de fichiers à l'avance.Les fichiers sont de deux types:

* Maps: : cartes contenant des données géographiques sur un pays ou une région.

* DEMs (Digital Elevation Maps) qui contiennent des données altimétriques du terrain;

Initialement, l'application ne contient ni cartes ni DEMs.

Vous serez invité à télécharger la carte de l'endroit où vous êtes. Plus tard, vous pouvez également télécharger plus de cartes.

DEMs sont facultatifs et permettent une méthode alternative pour obtenir l'altitude et pour afficher les lignes de niveau. Si vous maintenez enfoncé un point sur l'écran, vous serez guidé pour télécharger le DEM correspondant (couvrant 1°de latitude x 1°de longitude). Une fois que vous obtenez le DEM, vous pouvez voir les lignes de niveau de cette zone de la même manière, en appuyant sur un point sur l'écran.

Pour plus de détails, voir aide / Info.
