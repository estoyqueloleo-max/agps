Localização do GPS

Para rastrear uma rota, o aplicativo deve ter permissão para usar os Serviços de localização do telefone.

De preferência, a localização deve ser definida de forma de alta precisão, com todas as redes GPS, Wi-Fi e móveis ativadas. Embora o GPS seja essencial, as redes Wi-Fi/móveis fornecem dados que aceleram a determinação da localização inicial, mas são opcionais: se não estiver ativado, a definição de localização inicial também pode demorar alguns minutos.
