Política de Privacidade

1. Visão geral

Esta política de Privacidade é usada para informá-lo sobre as políticas com a coleta, uso e divulgação de informações pessoais de pessoas usando este aplicativo.

Este aplicativo usa um banner no final da página para publicidade. O usuário tem a opção de pagar uma pequena quantia para saltar a publicidade.

2. Qué información se recopila y por qué

Este aplicativo usa dados de localização móvel apenas para rastreamento de posição sob controle do Usuário e não é transferido para fora do dispositivo móvel.

A publicidade e os pagamentos são gerenciados pelas seguintes bibliotecas de terceiros do Google, que podem coletar e compartilhar informações pessoais com terceiros:

  • Google Play Services qa ue oferece APIs para gerenciamento de locais ,serviços de segurança e outros recursos vitais necessários para o desenvolvimento de aplicativos Android.

  • AdMob/AdSense: Plataformas de publicidade de aplicativos móveis do Google.

A Política de Privacidade completa dessas bibliotecas e serviços do Google é definida e explicada em https://policies.google.com/privacy.

Isso inclui:

* informações de serviço,

* dados confidenciais coletados,

* intercâmbio e proteção de informações,

* retirar a autorização.

3. Segurança

O aplicativo conta com o sistema operacional Android padrão e segurança dos serviços do Google, não foram implementadas medidas específicas de segurança do App.

4. Links para outros sites

Este aplicativo integrou links para o site https://estoyqueloleo-max.github.io/agps/, contendo informações de Ajuda / informação. Este site é usado apenas para fornecer informações, não exigindo login e não usando qualquer forma de perfil/cookies.

5. Privacidade das crianças

Estes serviços não se dirigem a menores de 16 anos.

6. Distribuicao

O único canal oficial para a distribuição deste aplicativo é:

  • Google Play Store https://play.google.com/

Esta política de Privacidade é eficaz para a distribuição feita apenas no canal oficial.

7. Alterações a esta Política de Privacidade

Em caso de atualização desta política você será informado.
