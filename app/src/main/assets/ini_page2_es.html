Almacenamiento de pistas y fotos

Esta aplicación almacena permanentemente fotos y pistas (archivos GPX) en un directorio de almacenamiento dedicado que no se destruirá incluso si la aplicación se desinstala.

Con el botón de abajo se abrirá una ventana del sistema donde deberá crear este directorio y conceder el consentimiento de acceso. El nombre sugerido de este directorio es "AGPS-Tracker".

Advertencia: se abre la ventana que muestra el contenido de un directorio ya existente (por ejemplo, "Downloads"). Debe usar los comandos del menú para crear un directorio al mismo nivel de directorios del sistema como " "Alarms" , "Downloads" , "Pictures", etc. Desafortunadamente, esta no es una operación fácil para todos los usuarios, si tiene alguna duda, intente ver el video de demostración y repita la operación.

En caso de que ya haya instalado versiones anteriores de esta aplicación "AGPS-Tracker" ya existe, pero debe otorgar el consentimiento para acceder.
