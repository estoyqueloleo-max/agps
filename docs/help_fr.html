AGPS-TrackerOm — Aide et Guide Utilisateur

Cette page détaille les fonctionnalités avancées introduites par AGPS-TrackerOm (cartes vectorielles hors-ligne et courbes de niveau). Les fonctions standards de suivi GPS sont expliquées dans la page des Fonctionnalités Générales.

Cartes Géographiques Hors-Ligne

Les cartes utilisées par AGPS-TrackerOm sont des cartes vectorielles gratuites et utilisables hors-ligne créées par le projet OpenStreetMap (© contributeurs OpenStreetMap). Ces cartes sont compressées dans des fichiers avec l'extension .map et peuvent être téléchargées directement dans l'application.

Lors du premier lancement, votre archive de cartes locales est vide. Vous serez invité à sélectionner et transférer la carte de votre région ou pays.

Pour télécharger d'autres cartes, utilisez le menu Téléchargement de Cartes. Vous pouvez parcourir les dossiers géographiques pour trouver votre zone. Vos cartes enregistrées peuvent être gérées depuis le menu Vos Cartes.

Courbes de Niveau

Les courbes de niveau sont générées automatiquement en maintenant enfoncé un point sur la carte. Elles sont calculées à partir des données altimétriques de modèles numériques d'élévation (DEM) de la mission SRTM de la NASA (précision d'un point tous les 30 mètres).

Les fichiers DEM portent l'extension .hgt et correspondent à des coordonnées géographiques précises (par exemple N44E008.hgt). Vous pouvez visualiser la couverture de vos fichiers DEM via le bouton Domaines DEM.

Altitude et Précision Altimétrique

L'altitude calculée par les signaux GPS satellites est sujette à d'importantes variations. Les modèles DEM offrent un calcul altimétrique beaucoup plus stable et précis fondé sur la position géographique horizontale.

AGPS-TrackerOm fonctionne par défaut en mode Auto : si un fichier DEM est disponible pour votre zone, l'altitude est interpolée depuis le DEM ; sinon, l'altitude GPS est conservée.

Édition des Traces GPX

Une trace GPX enregistrée peut être facilement modifiée :

  1. Fusionner deux traces : chargez une première trace puis ajoutez-en une deuxième pour les relier.
  2. Modifier ou supprimer des points d'intérêt (POI / Waypoints).
  3. Ajouter de nouveaux POI sur la carte ou le long de l'itinéraire.
  4. Enregistrer vers un nouveau fichier GPX standard.

Crédits

Cette application s'appuie sur des composants open source majeurs :

  • Cartes : OpenStreetMap.
  • Données altimétriques DEM : NASA SRTM et USGS EROS Data Center.
  • Rendu cartographique : Mapsforge API.
  • Thème de carte Elevate : Développé par Tobias Kühn (OpenAndroMaps).
